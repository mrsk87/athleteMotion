# Empacotamento e Distribuição Windows (Athlete Motion Desktop)

Este diretório contém os scripts e especificações para geração de binários e instaladores Windows:
- `athletemotion.spec`: Especificação PyInstaller (modo `onedir`).
- `installer.iss`: Script do compilador Inno Setup para geração do `AthleteMotionSetup.exe`.
- `assets/`: Ícones `.ico` e artes do instalador.

Tarefas relacionadas: [../TASKS/D15_PACKAGING_INSTALLER.md](../TASKS/D15_PACKAGING_INSTALLER.md).
